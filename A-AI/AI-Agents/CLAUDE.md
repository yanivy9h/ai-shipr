# AI-Agents — Index

12 persistent agents, each a fixed lens. Read only the agent file you are about to run. All agents follow `_Security-Boundaries.md`.

## When to invoke which

**Framing & strategy**

| Agent | Invoke when |
|---|---|
| `Problem-Framer.md` | Problem statement is vague, contested, or missing outcomes |
| `Product-Strategist.md` | Building or refreshing full product strategy (JTBD, OST, OKR) — one level above initiative work |
| `Lean-Product-Canvas.md` | Build, review, or export a Lean Product Canvas — orchestrates discovery skills per box |

**Decisions & rigor**

| Agent | Invoke when |
|---|---|
| `Decision-Architect.md` | Complex decision with competing options or undefined criteria |
| `Structural-Integrity-Auditor.md` | Auditing any artifact for structural gaps before it moves forward |

**Signals & alignment**

| Agent | Invoke when |
|---|---|
| `Product-Signal-Reader.md` | Interpreting raw analytics — after a launch (24–48h of data) or when metrics are contested |
| `Stakeholder-Translator.md` | Preparing for an alignment meeting, expecting pushback |

**Growth & knowledge**

| Agent | Invoke when |
|---|---|
| `PM-Coach.md` | Interpersonal challenges, stuck between options, debriefs, skills growth |
| `Learner.md` | Scanning new files in `I-Information/Resources/` for relevance to current work |

**Lead mode only** (`team_mode: lead` in Settings.md)

| Agent | Invoke when |
|---|---|
| `Portfolio-Strategist.md` | Portfolio view, bet coverage gaps, allocation, exec portfolio update |
| `Team-Manager.md` | 1:1 prep, struggling PM, difficult feedback, team health |

**System**

| Agent | Invoke when |
|---|---|
| `SHIPR-Guide.md` | "How do I..." questions about AI-SHIPR itself. Typeable as `/shipr-guide` |

## Key context

Always read strategy context (`S-Strategy/`) before running any agent — generic output is worse than no output. `_Security-Boundaries.md` governs disclosure of internal content; `README.md` here is the human-facing version of this index.
