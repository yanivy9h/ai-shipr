# H-Hypotheses — Index

Filed, falsifiable hypotheses. One file per hypothesis, created from `Hypothesis-Template.md` (`HYP-###-short-name.md`).

## Key context

Every hypothesis must be falsifiable — metric, threshold, and time boundary — and link back to an initiative or bet. Flag any that are not. Status field (`Untested | Testing | Validated | Invalidated`) is read by `Roadmap-Planner`, `Experiment-Review`, and `/today`; keep it current. `Hypothesis-Builder` (skill) writes here; `Performance-Tracker` (skill) closes the loop with data. In discovery stage (`product_stage: discovery`), this is the most important folder in the system — if empty, suggest running `Assumption-Extractor` on the current bets first.
