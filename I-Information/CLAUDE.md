# I-Information — Index

Everything the system reads from the outside world.

## Doc index

- `Resources/` — articles, research, frameworks the PM dropped in for the system to learn from. The `Learner` agent scans files here that lack `processed: true` frontmatter.
- `Templates/` — reusable document structures: PRD, 1:1, retro, stakeholder update, OKR, decision log, sprint review, competitor watch list. Read the matching template before generating any of these document types.
- `Templates/Plans/` — saved document plans (reviewed structure + named skill sequence per recurring doc type). Check here before generating a PRD, board update, pitch, or strategy doc — a saved plan overrides the skill's default structure. See `A-AI/AI-Playbooks/When-Writing-a-Major-Doc.md`.
- `Integrations/` — data piped in from connected tools, one subfolder per tool: Slack, Email, Teams, Tickets, Miro, Figma, Excalidraw, MeetingTool (Fireflies/tl;dv/Granola/Zoom). Check Settings.md for which integrations are active before reading.

## Key context

Prefer summaries over full transcripts when both exist — read the full source only when the summary does not answer the question.
