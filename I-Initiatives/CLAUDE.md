# I-Initiatives — Index

The active work layer — one file per initiative (`initiative-[short-name].md`, copy `Initiative-Template.md`). Bridge between strategy and proof: every initiative traces back to a Strategic Bet and forward to at least one hypothesis. Flag violations of either.

## Key context

Each file carries: Strategic Link, measurable Outcome, Linked Hypotheses, Stakeholders, Stage, Status (`Active | At Risk | Paused | Completed`), Decision Needed.

**Stage lifecycle** — keep current, workflows branch on it:

```
Defined → In Sprint → In Development → Testing → Launched → Monitoring → Iterating
```

Read by `/today` (Active initiatives → priority stack), `Initiative-Review`, `Sprint-Planner`, `Roadmap-Planner`, `Launch-Coordinator`, and the `Structural-Integrity-Auditor`. More than 3 simultaneously Active initiatives is a capacity risk — flag it.
