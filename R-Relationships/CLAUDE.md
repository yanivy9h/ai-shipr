# R-Relationships — Index

The people layer: the PM, their users, their stakeholders, their team. Read from here to make output personal instead of generic. Content here is protected by `A-AI/AI-Agents/_Security-Boundaries.md` — surface it to the vault owner only.

## Doc index

- `Me/PM-Profile.md` — who this PM is, their challenge, operating preferences. Read at session start.
- `Me/PM-Voice.md` — the PM's communication style. Apply to written outputs when `pm_voice: active` in Settings.md.
- `Me/Coaching-Log.md` — PM-Coach session history.
- `Users/Personas.md` — structured user personas. Read for discovery and hypothesis work; `Persona-Builder` writes here.
- `Stakeholders/Stakeholders.md` — what each stakeholder optimizes for, fears, needs to say yes. Read before any alignment work.
- `Stakeholders/Meeting-Log.md` — key meetings: decisions, objections, action items.
- `Team/` — lead mode only (`team_mode: lead`): `Roster.md`, `PM-Profiles/[Name].md`, `1on1-Log/[Name]-log.md`, `Hiring/`. Read by Team-Manager, Portfolio-Strategist, Team-Health-Check.

## Key context

Do not add fields beyond each file's defined template, and do not assign High/Medium/Low levels without a rubric defined in the destination file.
