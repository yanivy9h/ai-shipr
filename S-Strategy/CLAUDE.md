# S-Strategy — Index

The permanent context layer. Read before almost every agent or skill run — without it output is generic.

## Doc index

- `Vision.md` — product in one sentence, vision, explicit will-NOT-do list. Read for any framing or strategy work.
- `Product.md` — product description, target segments, core user problem. Read when audience or scope matters.
- `KPIs.md` — North Star Metric + 3–5 supporting metrics with current/target. Read for OKRs, performance reads, business cases.
- `Strategic-Bets.md` — max 3 bets with success signal and horizon. Read for prioritization, planning, initiative linkage — every initiative must trace to a bet here.
- `Constraints.md` — team capacity, technical and budget limits. Read for sprint planning and roadmap sequencing.

## Key context

S is the anchor of the chain: S-Strategy (why) → I-Initiatives (what) → H-Hypotheses (how we'll know) → P-Proof (did it work). If a conversation decision contradicts a file here, name the conflict and offer the edit before continuing. In `product_mode: multi`, these files live per-product under `[product]/S-Strategy/` — check Settings.md first.
