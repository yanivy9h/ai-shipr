# Security Policy

AI-SHIPR is a folder-based system of Markdown files, configuration, and prompts — it does not run a server or process untrusted input at scale. Still, if you find a security or privacy issue (for example, a template or workflow that could leak sensitive product data, or a config that exposes credentials), we want to hear about it.

## Reporting a vulnerability

**Please do not open a public issue for security reports.**

Instead, email the maintainer directly:

- **getyaniv@gmail.com**

Include:
- A description of the issue and where it lives (file path or workflow)
- Steps to reproduce, if applicable
- The potential impact as you see it

You can expect an acknowledgment within a few business days. Once the issue is confirmed and addressed, we'll credit you in the fix unless you prefer to remain anonymous.

## Scope

In scope: anything in this repository — templates, agents, skills, workflows, configuration, and documentation.

Out of scope: vulnerabilities in third-party tools you connect AI-SHIPR to (Claude, Obsidian, Linear, Slack, etc.). Report those to the respective vendor.
